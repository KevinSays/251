Module 1 · Ascend

System Management

Topics

  • Linux basics: boot process, FHS, distros, licensing, CPU architectures, GUI stack
  • Kernel modules and initramfs
  • Hardware detection and monitoring
  • Storage: LVM, filesystems, mounting, RAID

Key facts

Boot process
Know thisWhat it means
Boot orderFirmware (BIOS/UEFI) → bootloader (GRUB2) loads the kernel → initramfs/initrd → real root filesystem → systemd
initrd / initramfsA temporary root filesystem with the drivers needed to mount the real root. If boot fails because a driver is missing, suspect the initramfs. It never holds user data
GRUB configChange /etc/default/grub, then regenerate. Never edit grub.cfg by hand: it gets overwritten
Regenerate GRUBRHEL/Fedora: sudo grub2-mkconfig -o /boot/grub2/grub.cfg · Debian/Ubuntu: sudo update-grub. Also needed if a new kernel doesn't show up in the menu
Build initramfsdracut (RHEL/Fedora; replaced the legacy mkinitrd) · update-initramfs -u (Debian/Ubuntu)
Look inside initramfslsinitrd (dracut systems) · lsinitramfs (Debian/Ubuntu)
PXENetwork boot: machines pull their boot image from a server. Used to deploy many workstations at once
Filesystem Hierarchy Standard
Know thisWhat it means
Why FHSThe same directory layout on every distro, so tools and admins know where things live
/etcSystem-wide configuration files
/bootKernel images, initramfs, bootloader files. First place to look when a system won't boot
/varVariable data that changes constantly: logs, spools, caches (not static config)
/tmpTemporary files, usually cleared on reboot
/sbinSystem binaries meant for root (on many modern distros it's a link into /usr/sbin)
/proc · /sysVirtual filesystems the kernel generates: process/kernel info and device/driver info
Distros, licensing, hardware platforms, GUI
Know thisWhat it means
Package familiesDebian/Ubuntu: apt + dpkg (.deb) · RHEL/Fedora: dnf + rpm (.rpm)
GPLCopyleft: if you distribute a modified version, you must release the source under the GPL. Internal-only use doesn't trigger this
Permissive vs. proprietaryPermissive licenses (MIT, BSD, Apache) allow closed derivatives. Proprietary software keeps its source closed
RISC-VOpen, royalty-free instruction set. Anyone can build or use it without a license fee
x86 vs. x86-6432-bit x86 can address about 4 GB of RAM; x86-64 (amd64) removes that limit. ARM is common in mobile, embedded, and cloud
Wayland vs. X11Wayland is the modern display protocol: simpler, better isolation between apps, better performance. X11 (X Server) is the legacy one
Display managersThe graphical login screen. GDM goes with GNOME; SDDM with KDE; LightDM is a lightweight option
Kernel modules
Know thisWhat it means
lsmodList loaded modules
modinfo nameModule details: description, file, parameters, dependencies
modprobe nameLoad a module and its dependencies. modprobe -r unloads it and unused dependencies
insmod · rmmodLow-level: load / remove one module file with no dependency handling
depmod -aRebuild the dependency map. Run it after manually installing or compiling a module
/lib/modules/$(uname -r)/Where a kernel's modules and dependency files (modules.dep) live
BlacklistingStop a module loading with a blacklist name line in /etc/modprobe.d/*.conf
Hardware tools
Know thisWhat it means
dmesgKernel ring buffer: what hardware the kernel detected at boot and driver messages. First check when a device seems missing
lscpu · lspci · lsusbCPU architecture and cores · PCI devices with vendor IDs · USB devices with IDs
lshwFull hardware hierarchy (run as root for complete detail)
dmidecodeReads firmware (SMBIOS/DMI) tables: memory size, speed, part numbers (dmidecode -t memory), serial numbers
ipmitoolTalks to the server's IPMI/BMC controller: sensors, power, out-of-band management
lm_sensorsTemperatures, fan speeds, voltages from the OS. Run sensors-detect once, then sensors
nvtopLive GPU usage, memory, and temperature (top for GPUs)
Storage
Know thisWhat it means
LVM layersPhysical volume (pvcreate) → volume group, the pool (vgcreate) → logical volume (lvcreate). LVs can span disks and be resized online
LVM viewspvs · vgs · lvs: short tables; pvdisplay/vgdisplay/lvdisplay: detailed
LVM operationsvgchange -ay vg activates all LVs in a VG · vgexport/vgimport move a VG's disks to another host
GrowingPartition: growpart (common on cloud VMs) → LV: lvextend → filesystem: resize2fs (ext4) or xfs_growfs (XFS). lvextend -r does the last two in one step
XFS vs. ext4XFS grows online but can never shrink. ext4 can grow, and shrink while unmounted. Btrfs adds snapshots and transparent compression
lsblk · blkidTree of disks, partitions, LVM · UUIDs and filesystem types
df -h · du -shFree space per mounted filesystem · size of a directory. du -sh /var/* finds what's filling /var
/etc/fstabWhat mounts at boot and with which options. Test edits with mount -a. /proc/mounts is the kernel's live view of what's mounted
Mount optionsnoatime skip access-time writes (faster) · noexec no running binaries · nosuid ignore setuid bits · nodev ignore device files
fsckChecks and repairs a filesystem. Only run it on an unmounted filesystem
InodesEach file's metadata and pointers to its data. The name lives in the directory entry, not the inode. df -i shows inode usage
Software RAIDmdadm --detail /dev/md0 array status · cat /proc/mdstat live status and rebuild progress
Network filesystemsNFS (Linux/Unix) · SMB/CIFS (Windows shares; Samba on Linux; SMB3 adds encryption)
fioStorage benchmark: IOPS, throughput, latency with configurable workloads

Commonly confused

Thisvs. thisThe difference
modprobeinsmodLoads by name and pulls in dependencies vs. loads a single .ko file with no dependency handling
modprobe -rrmmodRemoves a module and its now-unused dependencies vs. removes just that one module
dracutmkinitrdCurrent initramfs builder on RHEL/Fedora vs. the legacy tool it replaced
/etc/default/grubgrub.cfgThe file you edit vs. the generated file you rebuild from it (grub2-mkconfig / update-grub)
resize2fsxfs_growfsResize ext4 (grow or shrink) vs. grow XFS (no shrinking, ever)
dfduFree and used space per filesystem vs. how much space a directory tree uses
dmidecodelshwFirmware tables (RAM part numbers, serials) vs. a full tree of detected hardware
GPLProprietaryModified versions you distribute must stay open source vs. source stays closed

Practice

Try each one before you open the answer.

Boot

Q1. New kernel, same old menu

After a kernel update on a Fedora box, reboot shows only the previous kernel in the GRUB menu. What do you run?

Show answer

Regenerate the GRUB config: sudo grub2-mkconfig -o /boot/grub2/grub.cfg (sudo update-grub on Debian/Ubuntu). GRUB only knows about kernels listed in grub.cfg.

Kernel modules

Q2. The module you built yourself

You copied a freshly compiled driver into /lib/modules/$(uname -r)/extra/. modprobe mydriver says it can't find it. What's the missing step?

Show answer

sudo depmod -a. modprobe looks modules up in the dependency map (modules.dep), and that map doesn't know about the new file until depmod rebuilds it.

Hardware

Q3. Is it plugged in, or just not loaded?

A new network card doesn't appear in ip link. Which two commands tell you whether the hardware was detected at all, and whether a driver claimed it?

Show answer

lspci (or lspci -k, which also shows the driver in use) to see if the card is on the bus, and dmesg to read what the kernel said about it at boot.

Storage

Q4. Two steps, not one

You ran lvextend -L +10G /dev/vg0/home. lvs shows the bigger size, but df -h /home hasn't changed. The filesystem is XFS. What now, and what should you have run instead?

Show answer

sudo xfs_growfs /home grows the filesystem into the new space. Next time, lvextend -r resizes the LV and the filesystem together.

Storage

Q5. Hardening a data partition

A shared upload partition is mounted at /srv/uploads. Nobody should be able to run programs from it or use setuid files there. Which fstab options do you add?

Show answer

noexec,nosuid (add nodev too, so device files there are ignored). Remount with sudo mount -o remount /srv/uploads and check /proc/mounts.

Key facts

Name resolution and network config
Know thisWhat it means
/etc/hostsStatic name-to-IP entries. Usually checked before DNS, so an entry here overrides DNS
/etc/resolv.confWhich DNS servers to ask
/etc/nsswitch.confThe lookup order (e.g. hosts: files dns). If /etc/hosts works but DNS doesn't (or the reverse), check here
nmcliNetworkManager's CLI. Changes saved to a connection profile persist across reboots
NetplanUbuntu's YAML network config in /etc/netplan/. netplan apply applies it (no undo) · netplan try applies it and rolls back unless you confirm · netplan status shows current state
hostnamectlView or set the hostname
systemd-resolvedLocal DNS resolver/cache on many systems. resolvectl flush-caches clears its cache; if the service stops, name resolution breaks
Network tools
Know thisWhat it means
ping · ping6Reachability using ICMP. ping6 is the IPv6 version
ss -tulnListening TCP/UDP ports (numeric). Add -p for the owning process. Replaces netstat
digFull DNS answers, including which server responded and the TTL
nc -zv host portCan I open a TCP connection to this port? Quick firewall test
nmapPort scanner: which ports are open on a target
tcpdumpPacket capture on an interface. Needs root
iperf3Measures real throughput between two hosts (one runs the server, one the client)
ethtoolLink detected? Speed and duplex of a physical interface
arp · ip neighThe ARP cache: IP-to-MAC mappings on the local network
Shell basics
Know thisWhat it means
Key variablesHOME home directory · PATH where commands are searched for · PS1 prompt format · SHELL your login shell · USER username
PATHIf a program in /opt/tools/bin says "command not found," that directory isn't in PATH
Startup files~/.bashrc every interactive non-login shell · ~/.bash_profile login shells, once · ~/.profile the POSIX fallback for login shells
PathsAbsolute paths start with /; relative paths never do. ~ = your home. cd alone goes home; cd - toggles to the previous directory
History shortcuts!! repeats the last command; sudo !! reruns it as root
File descriptors0 = stdin · 1 = stdout · 2 = stderr
Redirection> overwrite · >> append · 2> stderr to a file · < read stdin from a file · <<EOF here document (inline input until EOF)
Pipes| sends stdout to the next command's stdin. stderr does not go through the pipe unless you add 2>&1
Text toolsecho / printf print · cut columns (awk works too) · grep search · sed find-and-replace (sed 's/old/new/g') · head/tail · less scroll and search
Backup and compression
Know thisWhat it means
tarArchives files, keeping permissions and directory structure. Alone it does not compress. -c create · -x extract · -t list · -v verbose · -f archive file
tar + compression-z gzip (.tar.gz) · -j bzip2 · -J xz. Create: tar -czf out.tar.gz dir · Extract: tar -xzf out.tar.gz
Compressorsgzip: fastest, most common · bzip2: middle · xz: smallest files, slowest. Each compresses one file; that's why tar comes first
gzip behaviorgzip file replaces it with file.gz (the original is gone unless you use -k)
Read compressed fileszcat print · zgrep search · zless page through. No need to decompress to disk
cpioArchiver that reads the file list from stdin. initramfs images are cpio archives
zip · unzip.zip files, common when exchanging with Windows
rsyncCopies only what changed. -a archive mode keeps permissions, times, links (no compression) · -z compress in transit · -v verbose · works over SSH (user@host:/path)
rsync --deleteRemoves destination files that no longer exist at the source. Test with --dry-run first
ddRaw block-by-block copy: dd if=/dev/sda of=/dev/sdb bs=4M status=progress. if = input, of = output; mixing them up destroys data
ddrescueLike dd for failing disks: skips bad sectors, retries later, and logs progress to a map file so it can resume
Virtualization
Know thisWhat it means
KVMKernel module that turns Linux into a Type 1 hypervisor using CPU extensions (Intel VT-x / AMD-V)
QEMUEmulator. Alone it can emulate other CPU architectures in software (slow); with KVM it runs at near-native speed
VirtIOParavirtualized drivers (virtio-net, virtio-blk) that speed up network and disk I/O compared with emulated hardware
qcow2 vs. rawqcow2: thin provisioned, snapshots, backing files (many VMs share one base image) · raw: plain byte-for-byte, slightly faster, uses its full size
qemu-imginfo virtual vs. actual size · convert change format · resize grow/shrink the virtual disk
libvirt toolslibvirt common API across hypervisors · virsh CLI · virt-manager GUI
VM networksNAT: VMs hidden behind the host's IP with a private subnet and virtual DHCP · Bridged: VMs are full hosts on the physical LAN · Host-only/isolated: VMs (and maybe the host) only, no outside access
VM featuresSaved state: RAM written to disk, resume later exactly where you left off · Live migration: move a running VM to another host (needs shared storage) · Nested virtualization: a hypervisor inside a VM

Practice

Try each one before you open the answer.

Shell

Q1. Errors and output in one file

You want a script's normal output and its error messages saved together in run.log, replacing any old log. Write the redirection.

Show answer

./script.sh > run.log 2>&1. The order matters: point stdout at the file first, then send stderr (2) to the same place as stdout (1).

Name resolution

Q2. One name, two answers

ping intranet reaches 10.0.0.9, but dig intranet returns 10.0.0.50. Which is right, and why do they disagree?

Show answer

ping resolves through nsswitch.conf, which normally checks /etc/hosts first. dig queries DNS directly. A stale /etc/hosts entry is overriding DNS for normal programs. Remove or fix it.

Backup

Q3. Shrink this archive

You archived a project with tar -cf project.tar project/, but it's too big to email. Recreate it with the best compression, accepting that it's slower.

Show answer

tar -cJf project.tar.xz project/. -J is xz, which gives the smallest result; -z (gzip) would be faster but larger.

Virtualization

Q4. Where did the 40 GB go?

A VM's disk shows as 40 GB inside the guest, but the image file on the host is only 6 GB. Which command confirms both numbers, and why are they different?

Show answer

qemu-img info disk.qcow2 reports the virtual size and the actual disk size. qcow2 is thin provisioned: it only takes up host space as the guest writes data. A raw image would use the full 40 GB right away.

Virtualization

Q5. Disk images for ten clones

You need ten test VMs that start from the same installed OS without storing ten full copies. Which disk format and feature?

Show answer

qcow2 with a backing file: one base image, and each VM's qcow2 overlay stores only its own changes. Raw images can't do this and always use their full size.

Key facts

Files and directories
Know thisWhat it means
Moving aroundpwd where am I · cd change directory · ls -l long listing (permissions, owner, size) · ls -li adds inode numbers
Creating and removingtouch empty file · mkdir -p a/b/c with parents · cp copy · mv move or rename · rm delete (no recycle bin) · rm -r a whole tree · rmdir only empty directories
ls -l type letter- file · d directory · l symlink · b block device (disks) · c character device (/dev/null, terminals) · s socket · p pipe
fileIdentifies the real type by looking at the contents, not the extension
statAll metadata: inode number, size, permissions, link count, access/modify/change timestamps
findSearches live, so it sees brand-new files: find /etc -type f -name "*.conf"
locateSearches a prebuilt database: fast, but misses files created since the last updatedb
diff · sdiffLine-by-line differences · side-by-side columns
lsofLists open files and which processes have them, e.g. lsof /var/log/syslog. Answers "why can't I unmount / delete this?"
Hard linksA second name for the same inode (link count goes up). Data survives until the last name is deleted. Can't cross filesystems
Symbolic linksln -s target name: a small file holding a path. Can cross filesystems; breaks if the target moves or is deleted
Users and groups
Know thisWhat it means
Creating usersuseradd -m -s /bin/bash name low-level, every distro · adduser name interactive and friendlier (Debian/Ubuntu)
/etc/skelTemplate files copied into every new home directory. Put a file here and every new user gets it
/etc/passwdOne line per account: username, x, UID, primary GID, comment, home directory, login shell. Readable by everyone
/etc/shadowPassword hashes and aging. Only root can read it. A ! at the start of the password field means locked
/etc/login.defsDefaults for new accounts: UID_MIN/UID_MAX, SYS_UID_MIN, password aging
UIDs0 = root (any account with UID 0 has full root power) · below 1000 = system/service accounts · 1000+ = regular users on modern distros
Modifyingusermod -aG group user add a supplementary group (keep the -a!) · usermod -s or chsh -s /bin/zsh user change shell · usermod -u change UID (then chown files outside the home directory)
New group membershipTakes effect at the user's next login. An existing session won't have it (newgrp or log out/in)
Lockingpasswd -l or usermod -L lock (account and files stay) · passwd -u or usermod -U unlock
Deletinguserdel name keeps the home directory · userdel -r name removes it too
chagePassword aging: chage -l user view · chage -M 90 user must change every 90 days
Looking up accountsid user UID, GIDs, groups · getent passwd all accounts from every NSS source (local files and LDAP), unlike reading /etc/passwd
Who logged inw who's on now and what they're running · who who's on · last login history · lastlog each user's most recent login · lastlog -b 90 users with no login in the last 90 days
Processes
Know thisWhat it means
Viewingps aux snapshot with CPU/memory · top live · htop live, interactive, colors, mouse · pstree parent/child tree
/proc/<PID>/The kernel's live info for one process: command line, open file descriptors, status
Deeper toolsmpstat per-CPU usage incl. I/O wait · pidstat per-process usage over time · strace system calls a process makes
STAT codesR running/runnable · S sleeping · D uninterruptible sleep, blocked on I/O · T stopped · Z zombie (exited, not yet reaped)
D and ZMany D processes + high load = I/O trouble (slow disk, hung NFS). D processes ignore even kill -9 until the I/O finishes. Zombies use no CPU/RAM, just a PID, until the parent reaps them
SignalsSIGTERM (15) default for kill, polite, process can clean up · SIGKILL (9) can't be caught or ignored · SIGHUP (1) many daemons reload their config · SIGINT (2) Ctrl+C
PriorityNiceness −20 (most favored) to 19 (least). nice -n 10 cmd starts with a niceness · renice changes a running process. Only root can raise priority
ulimitPer-shell resource limits: open files (ulimit -n), max processes (ulimit -u)
Jobs and scheduling
Know thisWhat it means
Background jobscmd & runs in the background, still tied to your terminal · Ctrl+Z stops the foreground job · bg %1 resumes it in the background · fg %1 brings it back · jobs lists
nohupIgnores SIGHUP so the job survives logout: nohup ./long-job.sh &
cronRecurring jobs. crontab -e. Fields: minute hour day-of-month month day-of-week, then the command. 0 2 * * * = 2:00 AM daily
atRuns a job once at a set time: at 23:00 · atq list · atrm remove
anacronFor machines that aren't always on: runs daily/weekly jobs that were missed while powered off

Commonly confused

Thisvs. thisThe difference
Hard linkSymbolic linkSame inode, survives deleting the original, same filesystem only vs. a path pointer that breaks if the target goes away
findlocateSearches live, slower vs. searches a database, fast but can miss new files
rmdirrm -rRemoves only empty directories vs. removes a directory and everything in it
useraddadduserLow-level, flags only, on every distro vs. interactive helper on Debian/Ubuntu

Practice

Try each one before you open the answer.

Files

Q1. The disk that won't unmount

umount /mnt/usb fails with "target is busy." How do you find out what's holding it?

Show answer

lsof /mnt/usb (or lsof +D /mnt/usb) lists the processes with files open there. Often it's a shell whose current directory is inside the mount: cd out and try again.

Files

Q2. Two names, one file?

ls -li shows report.txt and backup.txt with the same inode number and a link count of 2. You delete report.txt. What happens to the data?

Show answer

Nothing; it's still there. They're hard links to the same inode, and the data is only freed when the last link is removed. backup.txt's link count drops to 1.

Users

Q3. A new-hire welcome file

Every account you create from now on should start with a .vimrc and a WELCOME.txt in its home directory. Where do you put them?

Show answer

In /etc/skel. useradd -m and adduser copy its contents into each new home directory. Existing users aren't affected.

Processes

Q4. Make it play nice

A long video encode (PID 5120) is making the machine sluggish for everyone. You want it to keep running, just with less CPU priority. What do you run?

Show answer

renice -n 15 -p 5120. A higher nice value means lower priority. Making it more favored (a lower or negative number) would need root.

Scheduling

Q5. Write the schedule

Write a crontab line that runs /usr/local/bin/cleanup.sh at 11:30 PM every Sunday.

Show answer

30 23 * * 0 /usr/local/bin/cleanup.sh: minute 30, hour 23, any day of month, any month, day-of-week 0 (Sunday; 7 also works).

systemd
Know thisWhat it means
What it isPID 1: initializes the system and manages services
Unit types.service long-running daemons · .timer scheduled runs (paired with a .service of the same name; a cron alternative) · .target groups of units, a system state like multi-user or graphical · .mount mount points · .socket

Practice

Try each one before you open the answer.

Software

Q1. Where did it come from?

You installed a tool with pip install, but dnf list installed doesn't show it. Is something broken?

Show answer

No. Language package managers (pip, npm, cargo) keep their own records, so apt/dnf never see their packages. The same goes for software built from source with make install.

systemd

Q2. Run a job every night with systemd

You want report.service to run at 1:00 AM daily using systemd instead of cron. What do you create, and what's the gotcha?

Show answer

A report.timer unit with OnCalendar=*-*-* 01:00:00, then systemctl enable --now report.timer. The timer only triggers; it needs the matching report.service to exist.

systemd

Q3. Mount unit name

You want systemd to mount a disk at /srv/media/photos. What must the unit file be called?

Show answer

srv-media-photos.mount. Mount units are named after their path, with the leading slash dropped and the remaining slashes turned into dashes.

Containers

Q4. Same image, three environments

One container image must run in test and production with different database addresses. How do you avoid building two images?

Show answer

Pass the settings in at run time: -e DB_HOST=… or --env-file prod.env. Changing them later means re-creating the container, not rebuilding the image.

Containers

Q5. No network for this job

A container only processes files from a mounted volume and must not be able to reach any network. Which run option?

Show answer

--network none. The container gets only a loopback interface.
